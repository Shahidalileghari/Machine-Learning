# Essential ML Glossary

- **Algorithm:** procedure used to fit a model from data.
- **Baseline:** simple comparison approach.
- **Classification:** prediction of a category.
- **Clustering:** grouping examples by similarity.
- **Data leakage:** use of information that should not be available to the model or evaluation.
- **Feature:** model input.
- **Generalization:** performance on new data.
- **Hyperparameter:** developer-chosen configuration.
- **Inference:** using a fitted model to generate outputs.
- **Label/target:** value to predict.
- **Loss:** optimization penalty.
- **Overfitting:** learning patterns specific to training data that fail to generalize.
- **Pipeline:** chained transformations and estimator.
- **Regression:** prediction of a numeric value.
- **Regularization:** constraint/penalty that can limit complexity.
- **Train/validation/test:** fit/model-selection/final-evaluation data roles.
